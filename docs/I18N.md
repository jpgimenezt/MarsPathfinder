## Architecture

- `src/features/i18n/appI18n.tsx`: `LanguageProvider` owns one global `en | es` state (default `en`, regardless of browser locale); `aresroute.language` in `localStorage`, with a safe EN default if storage is unavailable or corrupted. Updates `<html lang>` and renders without navigation. The typed dictionary supports `{parameter}` interpolation and English fallback. `Intl.NumberFormat` and `Intl.DateTimeFormat` format presentation only; scientific values and calculation inputs are unchanged.
- `src/main.tsx` wraps the app. `index.html` starts with `lang="en"` before React hydrates. The selector in the application header remains accessible on narrow viewports. `useLanguage()` is used for component labels; local `ui(en, es)` pairs in legacy large JSX sections are an interim migration mechanism, not a replacement for typed keys. `localizedSources`, `localizedVikingBase`, `localizedScientificRegistry`, `localizedSurfaceImage`, `localizedColonyModule`, `localizedGaleDiscovery`, `localizedTerrainLayer` and `localizedDiscoveryStop` change presentation text without changing original IDs, URLs, coordinates, raster data or scientific algorithms.
- `AresMissionCommsModal` initializes from the global language, selects Matthew (EN) or Carlos (ES), updates both provider and local wake-word language on changes, and propagates explicit voice/manual switches back to the global selection. `amazonNovaSonicProvider` and the gateway now default to EN/Matthew; existing explicit ES remains supported. **Requires gateway restart/redeployment to affect deployed voice sessions.** Neither microphone recognition nor Nova Sonic speech was tested against a live AWS service in this task.
- `marsAgentService` sends `{ language: "en" | "es" }`. The **actual** Lambda prompt in `aws-agent/action_groups/lambda_function.py` reads this field and defaults to English, separately from `aws-agent/system_prompt.txt` (reference documentation). **Requires AWS Lambda redeployment**; the production endpoint may still respond in Spanish. No AWS or Vercel deploy was performed or verified.

## Outstanding before accepting full English

1. Complete bilingual review of remaining data-driven scientific narratives from `curiosityPathData`, mission-knowledge catalog entries and local tool messages; some source text was hidden/replaced in UI components but can still reach agent tool output. Audit live audio transcripts and legacy tour strings for Spanish leaks.
2. Audit voice error/confirmation/action tool outputs, transcript history after live language changes, AWS science-target tool JSON, local mission knowledge and fallback narratives. Historical transcript messages are not auto-translated (avoid rewriting a user's or model's own words); switching language affects subsequent responses.
3. Verify each gallery image against its linked NASA record before restoring sol/camera/date or georeferenced focus: those values were deliberately hidden and the focus button removed because photo-to-site registration is unverified. Verify acquisition date, coverage, license and quality of every dataset in the inherited registry before treating a listing as coverage at a clicked position. Do not describe the 3D procedural surface as a validated DEM.
4. Complete visual/a11y QA for all tour steps, every tab and modal and chat on real mobile devices and with a live voice gateway. Check English wrapping and Spanish persistence after reload. Build preview is not production verification.
